# Portafolio UGC — Emily Mora

## Antes de publicar
1. Exporta desde Canva las cuatro fotografías indicadas en `assets/LEEME.txt`.
2. Guárdalas dentro de `assets/` con esos nombres exactos.
3. Configura los cinco videos de Google Drive como **Cualquier persona con el enlace — Lector**.
4. Abre `index.html` en tu navegador para revisar la página.

## Publicar gratis con GitHub Pages
1. Crea en GitHub un repositorio nuevo y público, por ejemplo `portafolio-ugc`.
2. Entra al repositorio y pulsa **Add file → Upload files**.
3. Sube `index.html` y la carpeta `assets` con las imágenes.
4. Pulsa **Commit changes**.
5. Abre **Settings → Pages**.
6. En **Build and deployment**, selecciona **Deploy from a branch**.
7. Elige la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
8. Espera la publicación. La dirección será `https://TU-USUARIO.github.io/portafolio-ugc/`.

## Cambiar un video después
Abre `index.html`, busca el nombre de la tarjeta (por ejemplo `food-1`) y reemplaza el ID de Google Drive dentro de la URL que termina en `/preview`. Sube de nuevo el archivo a GitHub.

## Nota sobre los videos
Los cinco videos se insertan con el reproductor de vista previa de Google Drive. Drive puede mostrar su propia interfaz y tiene límites de reproducción; si un video no carga, verifica permisos o usa un alojamiento de video dedicado. El segundo espacio de Books queda como “Próximamente” porque se compartieron cinco videos, no seis.

## Nota sobre las imágenes
Las imágenes originales del código Canva tenían direcciones internas que no funcionan fuera de Canva. Debes exportar las cuatro fotos y añadirlas a `assets` para conservar el aspecto visual completo.
